# Pagdiwala Web App

This folder contains the React/Vite frontend for Pagdiwala, a free-size wedding turban rental service with appointment-based delivery and turban tying.

Run commands from the repository root:

```bash
npm install
npm run dev
npm run build
```

The production output is written to `dist/apps/web`. The generated files are static and do not require Node.js on the production server.

For Supabase authentication, order email notifications, deployment, and troubleshooting, see [docs/SETUP.md](docs/SETUP.md).
